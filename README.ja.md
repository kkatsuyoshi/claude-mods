# claude-mods / Usage

[English](README.md)

Claude Desktopにおいて、Claude Codeの入力欄の下に、利用状況をコンパクトに1行表示するmodです。

![Claude Desktopで、モデル選択の横に表示されたusage行](docs/screenshot.png)

```
usage c21 s77/3:39 w8
```

| 表示 | 意味 |
| --- | --- |
| `c21` | コンテキストウィンドウの使用率（%） |
| `s77/3:39` | 現在のセッション（5時間枠）の使用率（%）と、リセットまでの残り時間（時:分） |
| `w8` | 週間（7日枠）の使用率（%） |

## 注意事項

- **表示する場所：** Claude Desktop（Codeタブ）専用です。
  - ターミナル（CLI）の表示は変更しません。
  - 同じセッションをClaude Desktopとターミナルの両方で開いている間は、どちらにも表示しません。
- **更新のタイミング：** 表示は、Claudeが応答を終えるたびに更新されます。リセットまでの残り時間は1分ごとに更新されます。
- **表示しない項目：** 値が届いていない項目は表示しません。
  - 新しいセッションでは、最初の応答が届くまで利用上限（`s`と`w`）は表示されません。
  - サブスクリプション以外（APIキーなど）で使っている場合、利用上限は表示されません。
- **利用上限の値：** 同じ設定フォルダ（`CLAUDE_CONFIG_DIR`を設定していなければ`~/.claude`）を使うClaude Codeのセッションの間で値を共有し、このセッションと同じ枠の最新の値を表示します。
  - 他のセッションで使った分は、1分ほどで反映されます。
  - claude.aiのチャットや他の端末で使った分は、次の応答まで反映されません。そのため、Claude Desktopの使用量の表示より少なく出ることがあります。
  - 1つの設定フォルダを複数のアカウントで切り替えて使っている場合、このセッションの枠がリセットされたあと、次の応答までは別のアカウントの値が出ることがあります。

## インストール

Claude Code 2.1.287以降が必要です（modに対応した最初のバージョン。動作確認は2.1.295）。

1. Claude DesktopのCodeタブで、入力欄の下の「+」 → 「プラグインを追加」を開きます。
2. 右上の「+ 追加」 → 「マーケットプレイスを追加」 → 「リポジトリから追加」を選び、`kkatsuyoshi/claude-mods`と入力して「同期」をクリックします。
3. 「Usage」から「追加」をクリックします（「Usage」が見つからない場合は「プラグインを追加」の画面から、下にスクロールして「このコンピュータ」 → 「kkatsuyoshi」をたどってください）。

## アンインストール

1. Claude DesktopのCodeタブで、入力欄の下の「+」 → 「プラグインを追加」を開きます。
2. 下にスクロールして「このコンピュータ」 → 「kkatsuyoshi」をクリックします。
3. 「Usage」の右側、「…」のメニューより「削除」をクリックします。
